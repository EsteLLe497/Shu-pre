# heroine.fbx のプレビュー

`StartPreview.cmd` で起動し、左上の **Heroine preview** のモデル一覧から **heroine.fbx** を選びます。
一覧は `asset/model/Player_Movement` 直下のFBXから作ります。追加後は **Refresh models** で更新します。
**Player_Preview.fbx** を選ぶと従来モデルへ戻ります。**Load character** は手入力したパス、
**Reload Blender export** は従来のBlender出力を再読み込みします。読込失敗時は表示中のモデルを維持します。
プレビュー内の選択は本編へ自動反映しません。本編での切替は下記のF3タブを使います。

## モーション

右側 **Inspector → Motion → Clip** で再生する動きを選びます。
**Bind pose (no motion)** はアニメーションを外して、モデル本来の基準姿勢を確認します。
対応モーションが見つからないモデルも基準姿勢で表示できます。
切替後も表情は名前で引き継ぎ、存在しないモーフは選択・追加トラックから外します。

専用モーションはこのフォルダーの `Motions` に置きます。

```text
Player_Movement/
  heroine.fbx
  heroine/
    Motions/
      Idle.fbx
      Walk.fbx
      Run.fbx
      Nod.fbx
```

専用の `Idle / Walk / Run` は共有モーションより優先されます。
他のファイル名も **Refresh motions** で一覧へ追加できます。
ファイル名は半角英数字・空白・アンダースコア・ハイフン、64文字以内です。
専用ファイルがない動きは従来の共有 `Player_Movement/Motions` を試します。
FBXの内容を差し替えた場合は **Load character** でモデルごと再読み込みしてください。
**Refresh motions** は一覧だけを更新します。専用FBXが存在しても骨格が合わない場合、同名の共有FBXへ自動的に置き換えません。

現行ローダーは名前が一致する骨へアニメーションを適用します。体格や基準姿勢を補正する汎用リターゲットは未実装です。
Mixamoから取り込む場合は、このモデルと同じ骨格・基準姿勢へリターゲットして書き出してください。
骨名を単純に変更しただけで体格や軸の違いが解決するとは限りません。
Mixamoでの取得方法は [Adobeの説明](https://helpx.adobe.com/creative-cloud/help/mixamo-rigging-animation.html) を参照してください。

## 新モデルの調査結果

最初の書き出しではモーフ0でしたが、更新後の `heroine.fbx` はスキン骨147、モーフ57、埋込テクスチャ20、埋込アニメーション0を確認しています。
共有の待機・歩行・走行では43チャンネル中39の名前がスキン骨と一致します。
これはモーションの完全な互換性を保証する数値ではありません。腕や脚の長さが異なるため、足滑り・体形・関節を確認してください。

更新後のFBXには会話表情・瞬き・近距離閉眼に使うモーフがあります。
再書き出しする際もシェイプキーを保持してください。
旧モデルには57種類のモーフがあり、モデル切替で従来の表情プレビューへ戻せます。

## 検証結果

Debug x64ビルド成功。実プレビューで次を確認しました。

- モデル一覧に `Player.fbx / Player_Preview.fbx / heroine.fbx` を表示。
- `heroine.fbx` への切替と、共有の待機・歩行・走行を再生。
- 基準姿勢（Tポーズ）への切替と、モーション再選択による復帰。
- 従来モデルへ戻した後、57種類のモーフと表情UIが復帰。

専用モーションはまだ未配置です。追加取得・リターゲット後、その素材での動作確認が必要です。

## 本編でのモデル切替

ゲーム中に **F3 → モデル** を開き、一覧から `heroine.fbx` または `Player_Preview.fbx` を選びます。
FBXを追加した後は **モデル一覧を更新**、ファイルの内容を更新した後は **現在のモデルを再読込** を使います。

- 位置・向き・スケール、会話履歴、F3で調整した表情設定・視線設定を維持します。
- 切替成功時は移動テスト・単発モーションを停止し、待機モーションへ戻ります。
- 候補モデルとテクスチャ・必要モーションを別に読み込んでから差し替えます。失敗時は元の表示と移動状態を維持します。
- 表情モーフと視線用ボーンを新モデルから取り直します。旧モデルの閉眼モーフ名などを持ち越しません。
- モーフ0のモデルでも会話本文・字幕と、対応ボーンによる視線追従は使えます。表情・閉眼は使えません。
- この選択は起動中のみ有効です。再起動後の標準モデルは従来どおりです。
- 本編では待機・歩行などの必要モーションがないモデルへの切替を拒否します。基準姿勢だけの確認はプレビューで行ってください。

本編切替の検証: Debug x64ビルド成功。新モデルへの切替、位置・向きの維持、不正なFBXの読込失敗後も現在モデルが残ることを実画面で確認しました。
新モデルで笑顔を適用し、旧モデルへ戻して表情が復帰することも確認しました。表情206項目・移動23項目・視線と閉眼63項目は成功しています。
