# ゲーム内のローカルAI会話

F3 → **AI会話** → 内容を入力して **送信**。返答は画面下の字幕とF3の履歴に表示します。
F3を閉じても推論を続け、会話中も移動・アニメーション・描画を更新します。
キャンセルと会話クリアに対応し、クリア前の遅れた返答を後から表示しません。

## 導入・起動

このPCにはOllamaと `qwen3:4b` が導入済みです。Ollamaが起動していればゲームを起動するだけで試せます。
停止している場合はOllamaアプリを起動するか、既定の導入先ならPowerShellで以下を実行します。

```powershell
& "$env:LOCALAPPDATA\Programs\Ollama\ollama.exe" serve
```

新しいPCでAI会話も試す場合は [Ollama](https://ollama.com/download/windows) を導入し、ローカルモデルを用意します。

```powershell
ollama pull qwen3:4b
```

**Ollama未導入でもゲームは起動できます。** 未接続・モデル未導入・タイムアウト・不正な返答では定型セリフを表示します。
ほかの担当者はAI会話を実行する必要がなければ、Ollamaを入れる必要はありません。
起動時の自動通信・モデルの自動取得・クラウドへの切替はしません。

## ファイルの役割

| ファイル | 役割 |
|---|---|
| `DialogueTypes.h` | 設定、世界の状態、要求・応答の値型 |
| `DialogueProtocol.*` | UTF-8、JSON Schema、プロンプト、応答の検証 |
| `OllamaClient.*` | Windows標準HTTPによるローカル通信、期限・中止・応答容量制限 |
| `DialogueSession.*` | 専用ワーカー、履歴、結果受け渡し、古い応答の破棄 |
| `DialoguePanel.*` | F3の入力・状態・履歴と字幕の描画 |
| `../HeroineConversation.*` | メインスレッドでゲームの状態を取得し、結果を字幕へ反映 |
| `../asset/ai/ollama.cfg` | モデル名、ポート、時間・生成量・コンテキスト設定 |
| `../asset/ai/heroine-personality.txt` | ゲーム用ヒロインの人格。UTF-8、400文字以内 |

`Heroine`本体へHTTPやスレッド処理を入れません。通信側にはゲームオブジェクトや描画APIのポインターを渡しません。
既存のF3・ImGuiを流用し、F1・F2の機能は維持します。追加の有料API・APIキー・Python常駐サービスは不要です。
Windows SDKのC++/WinRTを利用し、対象の新規ファイルだけC++17に設定しています。既存CP932ソースの文字コードは維持します。

## 設定と制限

接続先は `http://127.0.0.1:11434`。ホストは固定で、F3ではポート・モデル・応答上限・生成量を調整できます。
設定の保存・読込は **Ollama設定** を開いて操作します。人格ファイルはゲームの起動時に読み込みます。

```text
heroineOllama 1
qwen3:4b
11434 45000 320 4096
```

最後の行はポート、待ち時間上限ms、最大生成トークン、コンテキスト容量です。
モデル名と設定値を検証し、HTTPリダイレクト・プロキシ・クラウドモデルを拒否します。
`/api/show`でローカルモデルを確認してから `/api/chat` を呼びます。要求全体に同じ期限を使い、本文は最大128KiBまで読みます。
Qwen3の思考だけで出力枠を使い切らないよう `think:false`、構造化応答のため `stream:false` を指定します。

質問は最大400文字、返答は最大240文字。直近最大4往復をRAM内に保持し、推論へ渡す履歴は最近の完全な往復から合計1,600バイト以内に絞ります。
失敗時の定型文はモデル用の履歴へ追加しません。会話本文をファイルやログへ自動保存しません。
同時要求はこの会話セッションで1件です。字幕は2行ずつ、文字数に応じた時間で自動切替し、F3の「字幕をもう一度表示」でも確認できます。

## 検証方法

ゲーム本体と同じVisual Studio 2022のC++ツール（v143）とWindows SDKで実行します。

```powershell
.\tests\RunDialogueTests.ps1
# 実HTTPの模擬サーバー検証（Python標準ライブラリのみ）
.\tests\RunDialogueTests.ps1 -Transport
# ローカルqwen3:4bとの実通信も確認
.\tests\RunDialogueTests.ps1 -Live
```

プロトコル・非同期履歴の48項目、実HTTPの13項目、サーバー停止時の1項目を検証します。
不正JSON、未知の行動フィールド、入力上限、UTF-8、履歴上限、中止、履歴消去後の古い応答、終了時の後始末を含みます。
HTTP側は応答遅延、本文受信中の遅延、要求全体の期限、巨大本文、chunked本文、転送拒否、クラウドモデル拒否を確認します。
初回のローカル実測では、固定の挨拶に約8.4秒で検証済みの日本語返答を受信しました。速度・返答内容は保証値ではありません。
実ゲームでもF3から日本語を送信し、約6.4秒で返答、F3履歴と画面下の字幕表示を確認しました。推論待ち中も描画を継続しました。
Debug x64ビルド成功。既存の移動23項目・視線と閉眼63項目も成功しました。

## 映画字幕

返信はCinecaption 2.26の白文字と細い黒縁で、画面下中央に最大2行ずつ表示します。
長文は省略せずページに分割し、1ページを最低3秒、約8文字/秒を目安に表示します。
日本語の句読点・括弧の禁則と英単語の区切りを考慮します（極端に狭い画面では1文字の表示を優先）。
F3 → AI会話 → 映画字幕で、字幕サイズと上下の黒帯（なし／字幕中のみ／常時）を変更できます。
初期値は字幕中のみ黒帯あり。設定は起動中のみ保持します。黒帯は描画上の重ね合わせです。
「字幕をもう一度表示」で先頭ページから再生できます。既存のデバッグUIのフォントは変更しません。

フォントは `asset/fonts/cinecaption226.ttf`、原文の説明書は `asset/fonts/cinecaption2.26.txt`。
ファイルは改変せず同梱しています。説明書は原文の文字コード（CP932）のままです。
フォントの再配布・商用利用は説明書で許可されています。著作権は原作者に帰属します。
Cinecaptionにない字形はWindowsの日本語フォントへフォールバックします。

字幕関連は `AI/SubtitlePanel.*`（描画・フォント）と `AI/SubtitleLayout.*`（改行・ページ・時間）に分離しています。
検証コマンド: `powershell -ExecutionPolicy Bypass -File tests/RunSubtitleTests.ps1`。
UTF-8、日本語禁則、英語折り返し、240文字の全文保持、2行制限、狭い幅、改行、ページ時間の53項目を確認しました。

Debug x64ビルド成功。実ゲームでローカルAIの返答を指定フォント・白文字・黒縁・下中央2行で描画できることを確認しました。
